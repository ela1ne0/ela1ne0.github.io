HackDuke 2026

HackDuke is a student-run hackathon at Duke University that aims to enable all students to use technology for social good. For the 2026 event, I was individually tasked with the end-to-end design of the main landing page. Following the completion of the landing page, I collaborated with a 7-member design team to scale this identity into a cohesive web ecosystem and custom assets for the extended scroll sections.

Role Product Designer ✴ Lead Landing Page Designer
Team 7 designers
Timeline 4 months (to build website)
Tools Figma, Figma Make, ReactJS
View website →

Results

Over four months, we built an atmospheric website that successfully supported a massive shift in registration performance. By translating expressive branding into a modular React system, we ensured the final product felt playful while remaining highly usable for a diverse applicant pool.

  • ~1,000 registrations (vs ~500 previous year)
  • ~80% increase year-over-year
  • Consistent visual ecosystem across 10+ touchpoints
  • Reusable system delivered for future HackDuke teams

Context & Goals

When we began, previous HackDuke branding felt fragmented. The visual language didn’t carry consistently across platforms, and the website hierarchy made calls-to-action less prominent than they should have been.

  • Create a memorable visual identity.
  • Improve website hierarchy and CTA clarity.
  • Build a system future teams could reuse.
  • Increase registrations year-over-year.

Concept Development

The Hook (Landing Page)

As the sole designer for the initial landing experience, I established the site's visual anchor: a vibrant, convenience-store-inspired theme. This playful but structured 'hero' moment set the creative direction and UI patterns for the entire web ecosystem.

Collaborative Scaling (Scroll Sections)

After defining the core aesthetic, I worked alongside the 7-member team to translate that visual language into modular scroll sections, ensuring every touchpoint felt like part of the same "convenience store" universe.

Building the System

Rather than designing a single set of static pages, we built a modular system that could scale across web, print, and environmental design.

Website Execution

I collaborated closely with developers to translate designs into React components. We iterated on hierarchy and spacing to ensure the most important actions were obvious, especially on mobile.

  • Strengthened CTA contrast and placement.
  • Simplified the registration path.
  • Improved mobile spacing and readability.
  • Reduced visual clutter while keeping personality.

Social Media Content

To ensure the HackDuke brand felt consistent beyond the website, we extended the visual language to Instagram.

Reflection

This project pushed me to design beyond individual screens and toward system-level thinking. I learned how to balance expressive branding with usability, and how to collaborate across design and development without losing cohesion.
